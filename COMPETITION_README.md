# Project guide

Start with README.md for the current models, results and commands. The report is report/report.pdf and its source is report/report.tex. ANALYSIS.md records the model decisions and limitations.

The folders notebooks and research_v2/previous_submission retain earlier work. Results in those folders describe earlier models. The current model settings are in model_config_v2.json.

The optional research scripts are not part of the normal submission workflow. The larger search took many hours and did not find a convincing replacement for the current models. Use saved summaries rather than repeating it.
